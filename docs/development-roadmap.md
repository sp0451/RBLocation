# 开发阶段与验收

本页定义阶段验收；M0 代码已实现，Android 单机主路径已通过[真机验证](validation/2026-10-20-android-mock-location.md)，异常场景与 iOS 出口尚未完成。当前构建与测试证据见 [实现状态](implementation-status.md)。首批 iOS 设备为 iPhone 16 Pro / iOS 27.0.1；Android 的设备/API 组合在实际测试时登记。实现按出口证据推进，不用界面完成度替代底层验证。

## M0：核心能力原型

目标：手工坐标输入、真实能力探测、单点设置、清除及可诊断会话状态。

1. 用 `get_cli 1.9.1` 创建 GetX Pattern 工程及页面，接入 `get: ^4.7.3`、GetMaterialApp、命名路由、InitialBinding 与页面 Bindings；以应用级 LocationSessionService 管理只读响应式快照，再创建本地 `location_bridge` 插件，确定 Pigeon schema 和错误映射。
2. iOS 验证开发者模式、设备准备、外部 LocalDevVPN、本机配对与开发者服务握手；配对凭据留在原生。
3. iOS 实现单点设置与清除、原生快照和事件，建立停止优先级、超时和资源释放策略。
4. 用 Apple Maps 与独立 Core Location 测试 App 观察坐标 A、B 和清除后的样本；随后记录用户关心的目标 App 行为。
5. Android 实现开发者选项授权检查、运行时权限、provider 注入、前台服务/停止通知与移除清理；不把地图或坐标显示当作注入证据。
6. 分别验证配对取消、拒绝权限、隧道丢失、重复设置与设置中清除，留下可复现的失败记录。

出口：每个平台独立达到“设置 A → 观察 → 设置 B → 观察 → 清除 → 观察”的真机证据；某个平台未通过时，只能标注该平台实验状态，不能宣称双端已支持。桥接与状态测试通过，失败路径能够解释并提供恢复入口。M0 可以没有地图、收藏和完整导航框架。

## M1：可用首版

目标：在 M0 已通过的平台上形成日常测试流程。

- 地图选点与手输共存；地图源可配置，坐标系映射有验证，断网可继续使用手输和已保存位置。
- 扩展已有 GetX 命名路由，加入主题、收藏/最近选择、非敏感偏好和脱敏诊断；不另加路由框架。
- 前后台、锁屏 1/5/15 分钟、Wi-Fi 切蜂窝、纯蜂窝首次连接、隧道断开和重新连接分别验收。
- 清除、关闭连接、强退和重启后，界面明确显示最新可得状态，不自动重放上次坐标；新进程的 disconnected 不能消除旧恢复提示。
- 使用自己的签名/侧载构建验证安装与刷新流程，记录依赖的外部隧道版本。

出口：支持能力表有已测/失败/未测标记；用户可理解当前坐标意图、命令结果与观测证据，能完成恢复操作。弱网、损坏存储或权限拒绝不导致错误成功提示。

## M2：扩展功能

在单点稳定后评估 GPX 导入导出、路线播放、速度、暂停/继续与摇杆。各项独立交付，不因地图插件存在就认为已具备路线搜索和规划服务。

路线输入需限制文件大小、点数、坐标范围、采样间隔和速度。移动任务交由原生运行时管理，Dart 页面销毁不改变执行语义；新设置、停止、断连与恢复必须有明确冲突规则。接入新插件前更新 [依赖选型](dependencies.md)。

## 验证层次

| 层次 | 关注点 | 不能证明的内容 |
| --- | --- | --- |
| 静态分析/编译 | 类型、符号、平台构建配置 | 真机协议可用 |
| 纯逻辑与界面测试 | 坐标、状态归约、事件顺序、停止优先级、持久化失败恢复；GetX路由Binding、页面释放与服务常驻、Obx更新范围 | 设备已改变位置 |
| 桥接/原生测试 | DTO 与错误映射、快照水位与事件合并、资源释放、串行命令、停止屏障、发送/确认区分、超时与旧回调失效 | 第三方 App 接受模拟位置 |
| 真机观测 | 独立观测位置、样本时间和模拟来源、目标 App 行为 | 所有系统版本或所有 App 通用 |
| 场景测试 | 后台、锁屏、蜂窝、断连、强退、重启、恢复 | 无限持续或永不失效 |

## 真机记录模板

每个真实场景建立 `docs/validation/YYYY-MM-DD-platform-scenario.md`，使用以下字段。当前不创建虚构测试记录。

```text
状态：未执行 / 通过 / 失败 / 结果不明确
日期与时区：
App 构建号、源码版本：
Flutter / Xcode / Android 工具链：
设备型号、完整系统版本与构建号：
idevice 固定提交、桥接 schema 版本、产物校验值：
外部隧道名称/版本、Wi-Fi/蜂窝状态：
前置条件：开发者模式/配对/权限/定位开关
步骤：设置 A、设置 B、清除或指定异常场景
命令证据：operationId、发送/协议可用确认/失败时间、证据等级
位置证据：观测 App、样本时间、新鲜度、精度、模拟标记
目标 App 结果：名称/版本、可见行为（逐个登记）
恢复结果：清除确认、后续样本、耗时、遗留问题
附件：脱敏截图或日志；不包含配对文件、密钥和完整设备标识
结论与适用范围：
```

坐标可用代号 A/B 和局部脱敏截图表达；精确数据只在受控测试环境保留。未执行场景始终标注未执行，命令回执与外部观测分别记录。

## 开发启动顺序
